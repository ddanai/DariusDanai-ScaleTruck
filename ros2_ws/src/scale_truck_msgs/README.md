# scale_truck_msgs

Custom ROS 2 interfaces shared across scale truck packages.

See [Actuator commands and sensor feedback](../../../docs/design/actuator-and-sensor-topics.md)
for the current command fields, units, sensor topics and reserved feedback status.

Expected contents:

- `msg/`: custom message definitions.
- `srv/`: custom service definitions.
- `action/`: custom action definitions.
